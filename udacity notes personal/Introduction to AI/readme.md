# Introduction to Artificial Intelligence — Topic List

Build a strong foundation in AI by exploring core concepts from both a theoretical and practical perspective. Blends essential principles with real-world problem-solving.

---

## Lessons

1. **Welcome to Artificial Intelligence**
   Course welcome/orientation.

2. **Introduction to Artificial Intelligence**
   Basic AI concepts and the challenge of answering "what is AI?"

3. **Solving Sudoku With AI**
   Applying AI to solve every Sudoku puzzle.

4. **Setting Up Your Environment and Workspaces**
   Setting up your own system using Anaconda (for those not using Workspaces).

5. **Constraint Satisfaction Problems**
   Expanding from constraint propagation (used in the Sudoku project) to the general Constraint Satisfaction Problem (CSP) framework.
