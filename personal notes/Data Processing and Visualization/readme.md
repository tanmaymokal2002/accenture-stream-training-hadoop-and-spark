# Data Processing and Visualization — Topic List

Applying sound design and data visualization principles to the data analysis process; using analysis and visualizations to tell a story with data.

**Project:** Communicate Data Findings

---

## Lessons

1. **Data Visualization in Data Analysis**
   Motivations for why data visualization matters and where it fits in the data analysis process.

2. **Design of Visualizations**
   Elements of visualization design, especially avoiding elements that cause a visualization to fail.

3. **Univariate Exploration of Data**
   Using matplotlib and seaborn to produce informative visualizations of single variables.

4. **Bivariate Exploration of Data**
   Using matplotlib and seaborn to look at relationships between two variables.

5. **Multivariate Exploration of Data**
   Using matplotlib and seaborn to visualize relationships/interactions between three or more variables.

6. **Explanatory Visualizations**
   Polishing exploratory plots into explanatory visualizations to convey findings to others.
