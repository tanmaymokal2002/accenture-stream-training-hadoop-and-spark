# Introduction to Data Analysis with Pandas and NumPy — Topic List

Course 6 | Data analysis process: questioning, wrangling, exploring, analyzing, and communicating data using Python (NumPy and pandas).

---

## Lessons

1. **The Data Analysis Process**
   Overview of the data analysis process and the Python packages used in this course.

2. **Jupyter Notebooks**
   Creating and using Jupyter Notebooks to share insights/visualizations alongside code.

3. **Exploring and Inspecting Data**
   Using pandas to load data, view its properties, and start asking data analysis questions.

4. **Manipulating Data using Pandas and NumPy**
   Data cleaning, filtering, reshaping; troubleshooting data issues; optimizing for memory/speed.

5. **Communicating Results**
   Drawing conclusions, calculating statistics, and creating basic visualizations with pandas.
